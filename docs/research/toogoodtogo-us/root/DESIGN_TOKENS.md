# Design Tokens - FoodSaver (Clone of Too Good To Go with Yellow Brand Theme)

## Brand Color Palette (Yellow / Gold Theme)
- **Primary Brand Yellow**: `#FACC15` (Yellow 400) / `#F59E0B` (Amber 500)
- **Primary Yellow Hover**: `#EAB308` (Yellow 500)
- **Yellow Accent Glow**: `#FEF08A` (Yellow 200) / `#FEF9C3` (Yellow 100)
- **Yellow Warm Surface**: `#FFFBEB` (Amber 50) / `#FEFCE8` (Yellow 50)
- **Dark Brand Obsidian (Contrast base replacing dark teal)**: `#18181B` (Zinc 900) / `#1C1917` (Stone 900)
- **Dark Surface Secondary**: `#27272A` (Zinc 800)
- **Text On Yellow**: `#18181B` (Black/Zinc 900 font-extrabold)
- **Text On Dark**: `#FFFFFF` / `#FEF08A` (Yellow highlight text)
- **Text Muted On Dark**: `#A1A1AA` (Zinc 400)
- **Text Body**: `#27272A` (Zinc 800)
- **Text Heading**: `#09090B` (Zinc 950)
- **Border Subtle**: `rgba(245, 158, 11, 0.2)` / `#E4E4E7`

## Typography
- **Font Sans**: Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif
- **Heading Styles**: Font-extrabold tracking-tight, uppercase kicker labels (`tracking-wider text-xs font-bold`)
- **Scale**:
  - H1 Hero: `clamp(2.5rem, 6vw, 4.5rem)` / line-height: 1.05 / weight: 900
  - H2 Section: `clamp(2rem, 4vw, 3.25rem)` / line-height: 1.15 / weight: 800
  - H3 Subsection: `1.5rem - 2rem` / weight: 700
  - Body Large: `1.125rem - 1.25rem` / line-height: 1.6
  - Body Regular: `0.95rem - 1rem` / line-height: 1.5

## Border Radius
- Button Pill: `9999px` (Full rounded)
- Cards: `1.5rem` (24px) / `2rem` (32px)
